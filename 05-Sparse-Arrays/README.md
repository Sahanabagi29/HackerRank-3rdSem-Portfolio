\# Sparse Arrays



\## Problem

Count how many times each query string appears in the given list of strings.



\## Approach

\- Read the list of strings.

\- Read the query strings.

\- Take each query one by one.

\- Compare it with every string in the original list.

\- Increase the count whenever a match is found.

\- Add the count to the result list.

\- Display the final counts.



\## Complexity

\- Time Complexity: O(N × Q)

\- Space Complexity: O(Q)
